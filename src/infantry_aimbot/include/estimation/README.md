# Estimation 模块

## 简介

承接前端检测结果，使用检测结果对目标的状态进行估计。此处主要针对目标几何结构和运动状态参数进行估计。

- 几何结构
  - h 中心点距离地面高度
  - dh 两组装甲板相较于中心点的高度，第一组为h+dh，第二组为h-dh
  - r1 第一组装甲板的半径
  - r2 第二组装甲板的半径
- 运动参数
  - 平移
    - px/py/pz(平移)
    - vx/vy/vz(速度)
    - ax/ay/az(加速度)
  - 旋转
    - tx/ty/tz(角度，这里的t指的是theta)
    - wx/wy/wz(角速度)
    - bx/by/bz(角加速度)

## 估计方案

目前主要使用$Kalman Filter$进行估计，主要的假设是前端检测时间间固定。

在处理噪声非高斯性较为严重，以及噪声本身很大的情况效果不佳。

## 估计流程

- 装甲板输入
- 装甲板追踪器更新
  - 根据历史数据区分装甲板组别
  - 输出状态分为未确定组别，和确定组别
- 整车追踪器状态更新
  - 根据整车的参合先验数据初始化KF
  - 如果单装甲板开始则初始化两个KF
  - 预测步+更新步，如果新的迭代由单装甲板转化为双装甲则根据状态更改装甲兵那跟踪器和当前整车组别对应关系
